## AI Coding Rules

1. Think before coding.
   State assumptions, surface ambiguity, and ask when the request has multiple valid meanings.

2. Simplicity first.
   Write the minimum code that solves the requested problem. No speculative features or one-use abstractions.

3. Surgical changes.
   Touch only files and lines required by the task. Match existing style. Do not refactor unrelated code.

4. Goal-driven execution.
   Define success criteria, make the change, then run the smallest useful verification.
