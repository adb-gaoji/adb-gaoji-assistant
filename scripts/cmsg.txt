chore(release): 沉淀 Release 创建脚本，统一发布流程

新增 scripts/create-release.js，把「建 Release + 写说明 + 记录 SHA256」
从手工操作变成一条命令：

- 从 VERSIONS.md 自动抽取当前版本段落作为说明
- 支持 --intro 指定本版重点（刷机加固这类需要展开讲的内容）
- 支持 --also 附带未单独发过 Release 的历史版本段落
  （本次 1.2.0 / 1.2.1 都没有单独发布，从 1.1.0 升级的用户
   需要知道中间改了什么）
- 自动计算安装包 SHA256 并写进说明，下载者可核对完整性
- 幂等：Release 已存在时更新说明而不是报错

与 upload-release.js 的分工写在 CONTRIBUTING 里：附件 500 MB 上传慢，
说明文字却可能随时改，拆开可以只改文字不重传安装包。

CONTRIBUTING 的发布步骤同步更新为 5 步，并补上 --also 的用法。
