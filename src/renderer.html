推荐操作

先连接手机并完成 USB 调试授权

连接向导会区分未连接、未授权、ADB 和 Fastboot 状态。

快速操作

连接成功后，可从这里直接切换设备运行模式。

连接向导

自动判断未连接、未授权、ADB 或 Fastboot 状态，并给出下一步。

1
检测连接读取 ADB 与 Fastboot 设备列表
2
判断问题识别授权、驱动、数据线和设备模式
3
执行修复按当前状态选择对应的连接工具
4
复测确认重新读取设备并更新连接状态
等待连接检测，检测结果和执行记录会同步到运行日志。

连接与投屏

连接稳定后再启动投屏，避免窗口反复断开。

Root 工具

Root 流程快捷操作

分区提取

提取 boot_a/b 与 init_boot_a/b 到桌面目录，布局和顺序与旧版一致。

一键刷机

选择官方 ZIP / XML 后直接按 XML 执行 Fastboot 命令，默认按脚本执行 erase、flash、reboot。

刷机脚本
点击“选择刷机包”选择 ZIP 或 XML。

选择后会解析 Fastboot 命令；确认手机已经进入 Fastboot 后点“开始刷机”。
